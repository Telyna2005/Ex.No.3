---

### **Prompting Techniques Used**

| **S.No** | **Prompting Technique**          | **Description**                                                                                     | **Example Prompt Used in Chatbot**                                                                       | **Purpose / Outcome**                                                                                                      |
| -------- | -------------------------------- | --------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------- |
| **1**    | **Straightforward Prompting**    | This involves giving the chatbot a direct and clear instruction to perform a specific task.         | *“Track my order number 54621.”*                                                                         | The chatbot retrieves and displays the current delivery status immediately.                                                |
| **2**    | **Tabular Format Prompting**     | This uses structured tabular input/output to organize information clearly for better understanding. | *“Show me the comparison between the two product models in a table.”*                                    | The chatbot displays product details (price, features, warranty) neatly in a table, improving clarity and decision-making. |
| **3**    | **Missing Word Prompting**       | This technique helps users fill in missing details in incomplete queries.                           | *User:* “Track my order for ____” → *Chatbot:* “Could you please provide the order ID to continue?”      | Enhances interactivity and ensures completeness of user inputs before execution.                                           |
| **4**    | **Preceding Question Prompting** | The chatbot refers to the user’s previous query to maintain conversational flow.                    | *User:* “My device isn’t turning on.” → *Chatbot:* “I see. Did you recently update the device software?” | Builds contextual continuity, making the conversation feel natural and human-like.                                         |
